01Cómo funciona

Flujo de un pedido: de la mención en GitHub al pull request revisado por una persona.

02Qué cambia frente a un agente normal

De «asistente al que le escribo» a «compañero de equipo al que le asigno tareas».

🧑‍💻 Agente tradicional

  • Espera a que abras la terminal.
  • Claude Code, Codex, Factory Droid.
  • Reacciona solo a tu instrucción directa.
  • No conoce lo que pasa en tu repo.

🤖 DeepSeek Super-Agent

  • Vive junto al repositorio.
  • Escucha GitHub (y opcionalmente Feishu).
  • Trabaja en segundo plano cuando se lo piden.
  • Actúa solo si una persona autorizada lo pide.
  • Mínima atención humana, máximo valor.

03Instalación en 8 pasos

Resumen de la guía oficial del repositorio (el setup lo guía un agente de programación).

Prepara el equipo

Node.js 22.19+, pnpm, git 2.32+, tmux, Python 3.8+ y GitHub CLI 2.48+.

Instala DeepSeek Harness

npm install -g @deepseek-ai/dsh@0.2.1-rc.3 y configura un proveedor de modelo.

Crea la cuenta del agente

Una cuenta de GitHub dedicada, con permiso de escritura en un repo secundario. Nunca tu cuenta personal.

Clona el prototipo

deepseek-ai/dsh-superagent-prototype y abre tu agente dentro de la carpeta.

Pide el setup guiado

«Lee SETUP.md y configura dsh-superagent conmigo» — pregunta a pregunta, con plan antes de ejecutar.

Acepta los valores seguros

Solo tu usuario en la lista, trabajo proactivo en observe y auto-merge desactivado.

Haz tu primer pedido

@<cuenta> <tarea> en un issue y revisa el ticket en el panel Superagent.

Revisa y fusiona tú

Aprueba el pull request y ajusta los prompts si el agente responde con ruido.

04Cuidados antes de usarlo

Recomendaciones del propio equipo de DeepSeek.

🧪 Es un prototipo

Puede tener errores y difiere de la versión interna; revísalo y adáptalo antes de usarlo.

🔓 Permisos amplios

Los trabajadores ejecutan comandos sin aprobación con tu usuario del SO; usa una cuenta de sistema dedicada para aislarlo.

🐣 Empieza pequeño

Un repo secundario, una lista corta de personas y sin auto-merge hasta que sea confiable.

📉 No para volumen

Evita pull requests masivos y mensajes que solo generan ruido al equipo.

05Preguntas frecuentes

¿Cuándo se lanzó?

El repositorio se publicó el 31 de octubre de 2026; Bloomberg lo reportó el 1 de noviembre.

¿Es gratis?

Sí, código bajo licencia MIT. Solo pagas el modelo de IA que conectes a DeepSeek Harness.

¿Necesito saber programar?

Necesitas manejarte con la terminal, GitHub y un agente que te guíe en la instalación. No es una app de un clic.

¿Puede fusionar cambios solo?

Puede, pero el auto-merge viene desactivado y se recomienda que las personas fusionen hasta confiar en el agente.

¿Sirve para producción?

Se presenta como prototipo de investigación. Pruébalo primero en un repositorio secundario.
